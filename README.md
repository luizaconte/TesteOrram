# Teste Orram - Luiza #

Levando em conta os requisitos apresentados, optei por desenvolver o teste em Java. Diante disso:

  -Os três petshops já estão pré-definidos com os preços especificados no enunciado, seguindo uma classe PetShop.
  
  -O cálculo do custo total do banho em um petshop é feito somando o custo individual para cada porte de cão.
  
  -O possível preço do combustível não foi levado em conta para o cálculo do gasto, sendo a distância um parâmetro apenas para desempate.
  

Busquei implementar um código simples, funcional e legível para outros desenvolvedores. Na pasta raiz é possível identificar um package para as classes Java ( uma classe para o PetSHop e outra para os valores dos banhos) e um package para o enum do porte dos animais, a pasta out possui os arquivos compilados, e ainda na pasta raiz se encontra a classe main do projeto (BuscarPetShop) e um arquivo app.jar que pode ser utilizado para a execução do sistema.

É necessário ter o jdk 21 instalado e esse processo pode ser feito atráves do link : https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html

Em seguida, é necessário executar o seguinte comando no diretório do projeto:  java -jar app.jar , como na imagem de exemplo
